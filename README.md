# **Challenge Amigo Secreto - Oracle - ONE Next Education 8ed**

Projeto desenvolvido para o desafio de amigo secreto, onde os usuários podem adicionar os nomes de seus amigos e realizar o sorteio de forma aleatória. O objetivo do projeto foi aplicar lógica de programação com JavaScript para criar uma aplicação interativa e funcional.

## **Tecnologias Utilizadas**
- **HTML5**: Estruturação da página e conteúdo.
- **CSS3**: Estilização da página.
- **JavaScript**: Lógica de interação, como adicionar amigos à lista e realizar o sorteio.
- **GitHub Pages**: Hospedagem do projeto online.

 ## **Demonstração**
 ![index](https://github.com/arianewelke/Challenge-amigo-secreto-ONE/blob/main/assets/index.png)


## **Funcionalidades**
- **Adicionar nomes**: O usuário pode adicionar os nomes dos amigos à lista.
- **Sortear amigos secretos**: Após adicionar os nomes, o usuário pode clicar para realizar o sorteio dos amigos secretos de forma aleatória, sem que ninguém tire a si mesmo.
- **Exibição dos resultados**: Após o sorteio, os pares de amigos secretos são exibidos na tela.
